# MCA 1st Sem Attendance & Internal Marks Portal (2026-28)

Live Web Application tracking attendance, subject-wise components (CT1-CT4, Mid-term, Assignments, TP-CO, Presentations), batch rankings, and schedule recovery calculations.

## Live Access
Open the web app directly in your browser or on mobile:
**[https://ss2771.github.io/mca-tracker/](https://ss2771.github.io/mca-tracker/)**

### Features:
- **Real-time Live Sync**: Fetches updates directly from the official Google Sheets.
- **Attendance Recovery Engine**: Projects the exact number of classes required to reach 75% based on 6 classes/day (Mon-Fri) and 4 on Saturday.
- **Internal Marks Segregation**: Complete breakdown of Class Tests, Mid-Terms, Assignments, Teacher Assessment, and Presentations.
- **Batch Leaderboard & Subject-wise Ranks**: Filterable by section and subject.
- **Mobile Optimized**: Responsive interface with Dark/Light theme toggle.
